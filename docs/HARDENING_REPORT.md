## Correctness changes

1. **Causal observations:** one shared offline/online event-to-frame path; initial zeros with explicit critical-channel missingness/age; forward hold; duplicate/older subsystem timestamps rejected. Runtime tick closure excludes future telemetry, links and commands. Caches publish atomically.
2. **Complete failure criteria:** shared thermal/SOC/absolute-attitude boundaries across generated labels, recorder, planner crossings and recovery. Planner receives observed wheels and attitude; missing enabled recovery evidence cannot certify safety.
3. **Supported actions:** generic isolation renamed `cut_heater`, restricted to an observed running heater. The action metadata names actual effects, prerequisites and verification/rollback expectations. Safe mode, observed ISL source block and quarantine retain their distinct effects. No wheel/battery repair is claimed.
4. **Uncertainty:** `UNKNOWN`, `KNOWN_LOW`, `KNOWN_HIGH` states. Unknown/high withholds link isolation and quarantine, permits local protective actions and requests ground review. The constant pre-action Q term is removed from candidate ranking, while Q remains in traces and gates.
5. **Provenance:** mismatched sources retained in a bounded evidence buffer with `SOURCE_MISMATCH`/`LOW_ASSURANCE`, excluded from trusted observations and trusted message clocks. Source declarations are not authentication.
6. **Consistency evidence:** EPS power balance and ADCS sensor-range checks complement thermal freeze/heater consistency. Supporting sensor/model evidence does not imply malicious intent. Thresholds require calibration for another plant.
7. **Evaluation:** additional no-SPARTA, no-coupling, temporal-only and telemetry-only ablations; held-out matched-origin hard episodes; paired actual-core nominal/mismatched-plant runs; stratified larger PGD sample with episode bootstrap intervals. `ensemble@0.85` is explicitly a fixed forecast operating point. The older snapshot-based closed-loop evaluator is labelled legacy and excluded from primary claims.
8. **Reproducibility:** paho packaging fixed; installed configuration verified outside the checkout. Checkpoints require exact causal-v2 channel metadata; old releases cannot silently load. Training child failures are fatal. The full-campaign freeze tool is provided; the deadline-bounded submission uses a separate manifest and exact subset indices.

## Interpretation and open boundaries

The headline forecast protocol targets 0.1% validation benign-step FPR. Test FPR is measured, not guaranteed; it differs from alarm events per satellite-hour. Pre-onset alarms are separate from valid warning lead. Fixed-threshold recall is not autonomous-action recall.

The hard set reduces origin/precursor shortcuts but remains generated by the same plant. The mismatch campaign changes only thermal plant parameters, not an independently implemented plant. The legacy evaluator still has access to simulator state and is not evidence for observation-only runtime policy. Graph benefit, attack attribution quality, robust uncertainty and general transfer must be assessed from measured comparisons; a saturated benchmark establishes none of these.

OPS-SAT is used for residual noise/gaps on synthetic trajectories. CuCD-ID is an independent cybersecurity audit role; SCAD is a propagation profile role. Native NOS3/cFS, ESA-ADB, real flight attacks and physical thermal dynamics are not validated by this campaign.

The ESP8266 firmware remains a thermal emulator. No physical board run, sensor/actuator calibration, embedded ARM latency or multi-node physical demonstration was performed. Action costs and one-tick simulator effects are configured assumptions, not measured spacecraft properties.

The supplied paper's 2.3 s first alert and the demo note's approximately 6 s first alert lack reconcilable raw logs. Neither is reused as a fresh result. No claim is made that this work prevents KA-SAT-like ground-segment destruction or a single destructive command with no observable precursor.
